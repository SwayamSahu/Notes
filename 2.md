# Demo Script — Fuel Route API (3 minutes)

**Before recording:** start the server with `.venv/bin/python manage.py runserver`
and pre-save the 5 API requests below as Postman tabs in order, plus one browser
tab for the map. Don't type URLs while recording.

Each step below has the **URL** to send, **what to point at** on screen, and a
**Script** block — that's the part you read out loud.

All numbers are real, so you can say them before you hit Send.

---

## Step 0 · Opening — 15 sec
*Nothing to click. Just talk over the Postman window.*

### Script
> "This API takes a start and a finish anywhere in the US, and works out the
> cheapest way to fuel the trip — which truckstops to pull into, how many gallons
> to buy at each, and what the whole thing costs. It's built on the 6,600-station
> price CSV from the brief. Let me just run it."

---

## Step 1 · The main route — 45 sec

**URL**
```
http://127.0.0.1:8000/api/v1/route/?start=Chicago, IL&finish=Houston, TX
```

**Point at (top of response):**

| Field | Value |
|---|---|
| `total_distance_miles` | 1085.2 |
| `total_cost_usd` | 324.91 |
| `total_gallons` | 108.52 |
| `fuel_stop_count` | 11 |
| `external_api_calls` | **1** |

### Script
> "Chicago to Houston, about 1,085 miles. We burn 108 gallons, and the cheapest
> way to buy that fuel is $324.91, across 11 stops.
>
> The number I really want you to see is the last one — **one** external API
> call. The brief asked for that. We only go out to the internet once, for the
> driving route itself. Turning 'Chicago, IL' into coordinates and all 6,600 fuel
> prices are local, so there's nothing else to call."

**Now scroll to `fuel.stops` and point at the first two entries.**

### Script
> "And here's the actual logic. Stop one is in Chicago at $3.40 a gallon — and we
> buy just **2 gallons** there. Almost nothing. Because 20 miles down the road
> there's a station at $3.15. So we buy only enough to reach the cheap pump, then
> fill up properly. It's not picking the nearest station, it's picking the
> cheapest one it can still reach."

---

## Step 2 · Caching — 15 sec

**URL** — exactly the same request, sent a second time
```
http://127.0.0.1:8000/api/v1/route/?start=Chicago, IL&finish=Houston, TX
```

**Point at `meta`:** `cached` → **true**, `external_api_calls` → **0**

### Script
> "Same request again — now it's cached. Zero external calls, back in about 3
> milliseconds instead of 700. Ten drivers ask for the same route, we pay for it
> once."

---

## Step 3 · The settings actually move the answer — 40 sec

**URL A** — tight detour, only 1 mile off the highway
```
http://127.0.0.1:8000/api/v1/route/?start=Chicago, IL&finish=Houston, TX&max_detour_miles=1
```
→ 19 stations usable · **$331.62**

**URL B** — wide detour, up to 25 miles
```
http://127.0.0.1:8000/api/v1/route/?start=Chicago, IL&finish=Houston, TX&max_detour_miles=25
```
→ 111 stations usable · **$322.50**

*(the default from Step 1 was 10 miles → 72 stations → $324.91)*

### Script
> "This setting is how far off the highway a truckstop is allowed to be. Stay
> within a mile and you've only got 19 stations to choose from, so you pay $331.
> Allow 25 miles, you've got 111 stations, and it drops to $322.
>
> Notice the cost only ever goes *down* as you allow more options. That's the
> check that the optimiser is doing real work — if widening the choice ever made
> it more expensive, something would be broken."

---

## Step 4 · Failing properly — 35 sec

**URL** — a truck that does 30 miles on a tank and won't detour
```
http://127.0.0.1:8000/api/v1/route/?start=Chicago, IL&finish=Houston, TX&range_miles=30&max_detour_miles=1
```

**Returns 422:**
```json
{"error": {"code": "no_fuel_coverage",
           "message": "No fuel station within the vehicle's range covers miles 64-85 of this route.",
           "gap_start_miles": 64.2, "gap_end_miles": 84.9}}
```

### Script
> "Last one — I've asked for something impossible. A truck that does 30 miles on
> a tank and won't go more than a mile off the highway. That trip can't be made.
>
> It doesn't crash, and it doesn't invent a route. It tells you that between mile
> 64 and mile 85 there is no pump you can reach — it names the exact stretch of
> road. That's something a dispatcher can act on: extend the range, or allow a
> bigger detour. Bad input gets the same treatment — a place outside the US, or a
> missing field, comes back as a 400 saying exactly what it wanted."

# Backup — only if they ask

**"Why only one API call?"**
> Coordinates are parsed directly, city names come from a list bundled with the
> project, and the fuel prices are the CSV loaded into memory at startup. The
> driving route is the only thing we genuinely can't do offline.

**"Is it actually cheapest, or a heuristic?"**
> Provably cheapest — the logic is in `routing/services/planner.py`. For every
> mile of road we take the cheapest pump close enough behind you to still have
> that fuel in the tank, sum it, and show that bound is achievable. It's the
> optimum, not a guess.

**"How fast is it?"**
> `compute_ms` is in every response — around 700 ms cold, almost all of it
> waiting on the routing service; ~15 ms for a new route on a road we already
> have; 3 ms on a repeat.

**"Where did the prices come from?"**
> The assignment CSV. Multiple price rows per truckstop are averaged, and each
> truckstop sits at its city centre — so detour distance is close, not exact.
> Every response lists this in an `assumptions` field.

**Spare requests, if you have time or they ask for something specific:**

| Case | URL |
|---|---|
| Raw coordinates | `/api/v1/route/?start=41.88,-87.63&finish=29.76,-95.36` |
| City with no state | `/api/v1/route/?start=Chicago&finish=Houston` |
| Coast to coast (shows `departure_fuel`) | `/api/v1/route/?start=Los Angeles, CA&finish=New York, NY` |
| Thirstier truck, smaller tank | `/api/v1/route/?start=Dallas, TX&finish=Denver, CO&miles_per_gallon=6&range_miles=300` |
| Skip tiny stops | `/api/v1/route/?start=Dallas, TX&finish=Denver, CO&min_purchase_gallons=5` |
| Missing field → 400 | `/api/v1/route/?start=Chicago, IL` |
| Unknown place → 400 | `/api/v1/route/?start=Zzzyxville, QQ&finish=Houston, TX` |
| Outside the USA → 400 | `/api/v1/route/?start=48.85,2.35&finish=Houston, TX` |
| Over the cap → 400 | `/api/v1/route/?start=Chicago, IL&finish=Houston, TX&max_detour_miles=999` |
| Health check | `/api/v1/health/` |
| POST instead of GET | `POST /api/v1/route/` with a JSON body |
